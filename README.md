## Projects

- [PowderMeet](https://github.com/zlichtman/PowderMeet): where should two skiers separated across a mountain meet? Graph routing over the resort's real lifts and trails finds the fairest spot. Live across 159 Epic and Ikon resorts.
- [Heartable](https://github.com/zlichtman/Heartable): one music library across Spotify and Apple Music, with diffable playlist backups and cross-service mixtapes.
- [Tsukumo](https://github.com/zlichtman/Tsukumo): a multi-agent harness where KemoSabe, a private bot on Apple's on-device model, stands between your personal data and every other AI agent.
- [MacSpaces](https://github.com/zlichtman/MacSpaces): a native macOS Nook for music and live lyrics, world clocks, coding tools, timers and files, right at the notch. Includes clipboard history, file baskets, on-device dictation and detailed nature themes. [Demo](https://www.zlichtman.com/macspaces) · [Download](https://github.com/zlichtman/MacSpaces/releases/latest/download/MacSpaces.dmg) · `brew install --cask zlichtman/tap/macspaces`
- [Tape](https://github.com/zlichtman/Tape): your windows side by side on one strip. Scroll along it with the keyboard or a swipe instead of shuffling overlapping windows. [Download](https://github.com/zlichtman/Tape/releases/latest/download/Tape.dmg) or `brew install --cask zlichtman/tap/tape`
- [Folio](https://github.com/zlichtman/Folio): fast sorting for your images and files, with search that even reads the text inside them. Tags and text recognition run on your Mac, and smart folders sort your library automatically. [Download](https://github.com/zlichtman/Folio/releases/latest/download/Folio.dmg) or `brew install --cask zlichtman/tap/folio`
